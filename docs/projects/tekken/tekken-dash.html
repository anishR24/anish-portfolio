Tekken 8 Interactive Roster

Pushing Tableau Beyond Business Templates Into High-Fidelity UI Design

Project Overview

This project re-imagines what is possible within data visualization platforms by completely stepping away from standard corporate grid structures. The goal was to build an immersive, high-fidelity interactive character selector that perfectly mirrors the premium UI/UX of modern fighting game selection screens.

By extracting flat rows of character metadata and combat statistics and translating them into a highly responsive asset, this design pushes Tableau’s layout engine, container stacking, and variable visibility to its maximum potential.

Analytical Strategy & Design

To transform standard data tracking tables into an arcade interface experience, I integrated tailored visual hierarchy rules and custom engineering steps:

  • Automated Data Scraping Pipeline: Because no consolidated dataset existed for the game’s launch roster, a custom Python ETL script was built using BeautifulSoup and Requests. Structural lore properties and fighter graphics were compiled from the Official Bandai Namco Tekken 8 Portal, while granular character attributes (such as official ages, blood types, heights, and titles) were parsed dynamically from the community-driven Tekken Fandom Wiki to create a clean, relational master schema.
  • Custom Repository & Shape Mapping: To construct the selection grid matrix, character image assets fetched during scraping were formatted, downscaled, and injected into a custom sub-directory inside the local My Tableau Repository/Shapes/ directory. By changing the marks card type to Shape, discrete character fields were mapped directly to their corresponding image transparent tokens, engineering a dynamic visual grid from tabular data points.
  • Custom Brand Integration & Typography: Leveraged high-impact gaming display layouts using specialized web-safe display fonts (Bebas Neue Pro paired with clean secondary sans-serif descriptive blocks) to directly mirror Tekken 8’s fierce design system.
  • Arcade Selection Grid Matrix: Arranged an intuitive portrait selector panel. Selecting individual cells isolates fighter visual assets while instantly updating adjacent calculation frameworks.
  • Simulated Single-Select Logic: Implemented rigid dashboard execution constraints and customized background sheet filters to completely eliminate default cross-highlight clutter, anchoring focus onto precisely one target profile at a time.

Key UI/UX & Technical Insights

1. The Dynamic “Empty State” Engine

To establish a premium application feel, the landing view utilizes layered visibility states. When zero active selections are filtered, the system cleanly isolates the core Tekken 8 brand splash and a localized “Select Your Fighter” callout. Triggering any individual node immediately trades this out behind a clean character overlay wrapper, dropping any ambient visual bleeding or text ghosting.

2. HUD-Style Vitals Processing

Fighter dimensions (Age, Height, Weight, Blood Type) bypass standard linear rows. Instead, they pass through layout-mapped calculations that distribute text strings cleanly inside independent structural coordinates—simulating a real-time game Heads-Up Display (HUD) menu.

3. Layer Management & Image Bleed Prevention

A major priority during final optimization was mastering spatial hierarchy. Because fighting game assets rely heavily on transparent, overlapping character artwork, layout blocks had to be rigidly contained. Fine-tuning the container background opacity and floating element order ensured that character profile artwork renders with clean edges and zero background asset collisions.

Technical Skills Demonstrated

  • Tool Frameworks: Tableau Desktop, Python (BeautifulSoup, Requests, Pandas).
  • Data Engineering: Web scraping, string parsing, regex cleaning, and data consolidation across disparate web models.
  • Asset Integration: Custom repository configuration, image palette asset mapping, and granular image asset alignment.
  • Layout Management: Advanced container nesting logic, relative floating asset placement, and strict Z-index ordering.
  • Interactions: Parameter actions, Dynamic Zone Visibility mapping, and custom layout object toggles.
